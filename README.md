# VideoCombine — скелет рішення

Стартовий каркас під архітектуру з документа. Будуй MVP, нарощуючи кроки.

## Структура

```
VideoCombine/
├── VideoCombine.sln
└── src/
    ├── VideoCombine.Core/            ← МОЗОК (не знає про WPF)
    │   ├── Pipeline/
    │   │   ├── IStep.cs               ← серце: "усе є крок"
    │   │   ├── PipelineContext.cs     ← спільна коробка між кроками
    │   │   ├── PipelineExecutor.cs    ← конвеєр: кроки по черзі
    │   │   ├── IProgressReporter.cs   ← звітування (live-прогрес)
    │   │   └── IPipelineProgress.cs   ← прогрес усього пайплайну
    │   ├── Steps/
    │   │   └── CutStep.cs             ← ПРИКЛАД повноцінного кроку
    │   ├── Providers/
    │   │   └── IUpscaleProvider.cs    ← патерн провайдера (лок./хмара)
    │   ├── External/
    │   │   └── ProcessRunner.cs       ← запуск ffmpeg/yt-dlp
    │   ├── Recipes/
    │   │   ├── Recipe.cs              ← модель JSON-рецепта
    │   │   └── RecipeStore.cs         ← читання/запис рецептів
    │   └── Models/
    │       ├── Models.cs              ← SourceVideo, Segment, Scene...
    │       └── AppSettings.cs         ← шляхи, ключі, ліміти
    ├── VideoCombine.App/             ← WPF (MVVM), лише GUI
    └── VideoCombine.Tests/           ← тести Core без GUI
```

## Як додати новий крок (головна точка розширення)

1. Створити клас у `Steps/`, що реалізує `IStep`.
2. Задати `TypeId`, `DisplayName`, `MaxConcurrency`.
3. У `GetRequirements` повернути передумови (напр. "потрібна транскрипція").
4. У `ExecuteAsync` зробити роботу, звітуючи через `progress`.
5. Зареєструвати тип, щоб конструктор у GUI його показав.

Решта програми не змінюється — це й є сенс архітектури "усе є крок".

## Як додати провайдера (апскейл / TTS / LLM / генерація)

Реалізувати відповідний інтерфейс (напр. `IUpscaleProvider`).
Локальні — синхронні; хмарні — `IsCloud = true`, усередині poll job-id.
У GUI це новий пункт у випадайці, решта не міняється.

## Наступні кроки до MVP (фази B–C з документа)

- [ ] `DownloadStep` (yt-dlp) + `AnalyzeStep` (ffprobe, ліниво)
- [ ] `AssembleStep` (склейка) — отримати перший результат "посилання → відео"
- [ ] WPF: таб Виконання з реалізацією `IPipelineProgress`
- [ ] WPF: таб Конструктор (список кроків + панель налаштувань)
- [ ] Підключити `RecipeStore` до GUI

## Принципи (з архітектурного документа)

- **Core ніколи не знає про App** — щоб ядро жило в консолі/тестах/майбутній веб-морді.
- **Кроки — конвеєр; паралельність усередині кроку** з лімітом за типом роботи.
- **Кожен крок звітує прогрес** — це частина контракту `IStep`.
- **Дрібні збої пропускаємо, критичні зупиняють.**
- **Рецепти — JSON без ключів**; ключі окремо й захищено.
